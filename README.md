# 万象 · 选择你的世界

一个纯静态的网页 App：不需要安装、不需要构建，可以直接部署在 GitHub Pages 上。
打开首页，会像游戏里「选角色」一样挑一个世界进入。

| 字 | 世界 | 内容 | 素材来源 |
|---|---|---|---|
| 画 | **画廊** `worlds/gallery/` | 七个主题展厅、横向漫步长廊、看画时缩放与拖拽、色彩漫游、私人收藏 | 芝加哥艺术博物馆开放接口，只用公有领域（CC0）作品，在浏览器里实时加载 |
| 星 | **星海** `worlds/cosmos/` | 3D 太阳系、行星档案、深空天体 | 程序生成，无外部素材 |
| 植 | **植物** `worlds/flora/` | 四季变换的世界之树、漂浮的 3D 植物角色、实拍图鉴 | 3D 由程序生成；35 张实拍照片来自 iNaturalist 开放数据（CC0 / CC BY / CC BY-SA），作者与授权见 `worlds/flora/photos/CREDITS.md` |
| 色 | **传统色** `worlds/colors/` | 中国传统色沉浸浏览、色谱、配色、分享卡 | 公开色名，色值仅作参考 |
| 游 | **游戏厅** `worlds/arcade/` | 五款原创游戏：远征（奇幻动作 RPG）、星际竞速（飞船赛车）、星轨（引力解谜，`worlds/game/`）、暗域（潜行追逐）、星环列车（跑酷），共用星尘账户 | 全部原创，画面与音效均由程序生成 |
| 鱼 | **水族箱** `worlds/aquarium/` | 3D 水草缸、云养（离线时间流逝）、造景编辑、星尘鱼店、鱼类图鉴 | 3D 由程序生成；鱼类实拍照片来自 iNaturalist 开放数据（见 `worlds/aquarium/photos/CREDITS.md`） |
| 书 | **书房** `worlds/books/` | 拟真书架与名家书单 | 只有书目介绍，不含正文 |

## 目录
- `index.html`、`hub/`：选择世界的首页
- `worlds/<名字>/`：各个世界，每个都是独立的页面
- `shared/vendor/three/`：Three.js r160（MIT 许可），已放进仓库，不依赖外部 CDN

## 本地预览
3D 世界用到了 ES 模块，需要用本地服务器打开，不能直接双击文件：
```bash
python3 -m http.server 8000
```
然后在浏览器里访问 http://localhost:8000

## 说明
- **自动画质**：3D 世界（星海、植物）会实时测量帧率，手机跑不动时自动降低分辨率、关闭泛光，设置记在本机（`shared/perf.js`）。
- **离线缓存**：通过 HTTPS 打开后会注册离线缓存（`sw.js`）。页面和代码优先走网络，保证看到最新版；图片和 three.js 先用缓存，第二次打开更快；断网时，打开过的世界仍可浏览。
- **字体**：Google 字体在后台加载，打不开时自动使用系统宋体，不会让页面白屏。
- 画廊需要联网，访问 `api.artic.edu` 和 `www.artic.edu`。第一次加载后，数据会在浏览器里缓存 7 天。
- 收藏、进度等信息只保存在本机浏览器中，不会上传到任何地方。
