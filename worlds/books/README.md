# MyBooks · 书房

一个拟真书架风格的书籍浏览 App。纯 HTML / CSS / JS，不用安装、不用构建，打开 `index.html` 就能用。

## 功能
- **门厅**：三扇书房门，可以选「华语书房」「世界书房」「名家书单」
- **拟真书柜**：木纹书柜和隔板，每层有铜牌分类（文学 / 历史 / 传记 / 商业 / 心理 / 哲思 / 科学）。书脊的颜色、厚度、高矮都不一样，还配了绿植、地球仪、书立等摆件
- **分类浏览**：全部、华语作者、外国作者、樊登读书、董宇辉推荐、经典必读、我的想读
- **书籍详情**：可以拖动旋转的 3D 立体书，包括金句或一句话读懂、简介、推荐来源和同架好书
- **搜索**：按书名、作者、原名或国家搜索
- **随机一本**：在当前书架上随机抽一本书
- **想读**：标记想读的书，标记保存在本地浏览器里
- 适配手机，可以「添加到主屏幕」

## 本地预览
直接双击 `index.html` 打开，或者运行：
```bash
python3 -m http.server 8000
```
然后在浏览器里访问 http://localhost:8000

## 上线（GitHub Pages）
打开仓库的 Settings → Pages，Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。

## 添加书籍
编辑 `js/data.js`，在 `BOOKS` 数组里按格式加一条即可。封面和书脊的颜色会自动生成。

> 「樊登读书」「董宇辉推荐」书目整理自公开信息，仅供参考。
