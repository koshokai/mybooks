# 用 VRoid Studio 为《沉没之后》捏角色

VRoid Studio 是 pixiv 推出的免费 3D 动漫捏人软件，不会画画也能做出很精致的二次元角色。
捏好的角色导出成 `.vrm` 文件，放进游戏后会自动替换现在的临时人物，并且会眨眼、有待机动作，头发和衣服会随动作飘动。

## 1. 下载
- 在 VRoid 官网下载 **VRoid Studio**（有 Windows 和 Mac 版，免费）。
- 打开后选「新建」，选女性或男性的基础模型。

## 2. 序章需要的两个角色

### 小满（邻座的小女孩，约 7 岁）
- **体型**：身高调到最低，头身比偏小孩（「身体」→ 整体身高、头部大小）。
- **脸**：圆脸，眼睛大而温和，不要太成熟的妆容。
- **头发**：黑色或深棕色，扎一个**马尾**，配一个小发圈。
- **衣服**：**珊瑚色连帽卫衣**（游戏里她穿这个），牛仔裤，小运动鞋。
- **性格**：爱画画、有点胆小但很勇敢。

### 主角（你）
- 序章大部分是第一人称，主要会看到**手和袖子**，后续章节会有背影和全身镜头。
- 年龄约 20 多岁，衣着朴素，比如深色外套或风衣，适合远行。
- 性别、长相按你自己的想法来。

## 3. 导出
1. 右上角「拍摄 / 导出」→「导出 VRM」。
2. 版本选 **VRM 1.0**（0.x 也可以）。
3. 「减少多边形」可以把发型和衣服的面数适当调低，手机会更流畅；贴图大小选 **2048** 就够。
4. 填写作者名；使用许可里，如果以后想商用，请把「商业用途」设为允许（角色是你自己做的，版权在你手上）。
5. 文件命名：
   - 小满 → `xiaoman.vrm`
   - 主角 → `hero.vrm`

## 4. 发给我
直接把 `.vrm` 文件发过来就行。我会放到 `worlds/tide/assets/characters/` 里，调整好光照和描边后上线。

## 小提示
- 捏人时多参考新海诚电影里人物的配色：干净、明亮、略带透明感。
- 不要用 VRoid 自带的「样例角色」直接导出发布，它们有自己的使用条款；从基础模型开始自己调整最稳妥。
